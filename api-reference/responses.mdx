`POST https://gateway.toolken.ai/v1/responses`

This endpoint proxies the OpenAI Responses API (stateful multi-turn). Include `X-Toolken-Key` for gateway authentication alongside your OpenAI API key. Attribution headers are supported. See the [Headers reference](/api-reference/headers) for the full spec.
