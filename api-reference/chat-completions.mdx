`POST https://gateway.toolken.ai/v1/chat/completions`

This endpoint is OpenAI-compatible. Toolken passes the request through to your configured provider and streams the response back. Include `X-Toolken-Key` for gateway authentication alongside your provider's credential header. All attribution headers (`X-Toolken-Feature`, `X-Toolken-Customer-Id`, `X-Toolken-Metadata`) are supported. See the [Headers reference](/api-reference/headers) for the full spec.
