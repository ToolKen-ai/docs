`POST https://gateway.toolken.ai/v1/embeddings`

This endpoint is OpenAI-compatible. Toolken passes the request through to your configured embedding provider and returns the response. Include `X-Toolken-Key` for gateway authentication and your provider credential header. Attribution headers are supported. See the [Headers reference](/api-reference/headers) for the full spec.
