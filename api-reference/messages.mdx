`POST https://gateway.toolken.ai/v1/messages`

This endpoint proxies Anthropic's native Messages API. Use your Anthropic SDK with `base_url` set to `https://gateway.toolken.ai` (the SDK appends `/v1/messages` automatically) and include `X-Toolken-Key` alongside the standard `x-api-key` Anthropic credential header. All attribution headers are supported. See the [Headers reference](/api-reference/headers) for the full spec.
