title: "API Reference Introduction"
description: "Overview of the Toolken gateway API — base URLs, authentication, and supported endpoints."
---

The Toolken gateway exposes an OpenAI-compatible HTTP API. The production base URL is `https://gateway.toolken.ai`; the staging environment is `https://gateway-staging.toolken.ai`. Every request must include the `X-Toolken-Key` header for gateway authentication alongside your upstream provider credentials. The API supports both streaming and non-streaming responses.
