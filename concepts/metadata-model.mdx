---
title: "Metadata Model"
description: "How Toolken structures and stores attribution metadata for analytics queries."
---

Attribution metadata is captured on ingestion and indexed against four reserved promoted dimensions — `customer_id`, `feature`, `environment`, and `session_id` — plus an open-ended JSONB store for arbitrary key-value pairs. The dashboard can group and filter by any promoted dimension in real time; arbitrary metadata keys are available for custom queries. No schema setup is required: new keys appear automatically the first time they are sent.
