---
title: "Error Codes"
description: "Complete reference for all Toolken gateway error responses."
---

All gateway errors use a consistent JSON body: `{ "error": { "message": "...", "type": "proxy_error", "param": null, "code": "..." } }`. The table below lists all error codes and their HTTP status.

| HTTP Status | Code | Meaning |
|-------------|------|---------|
| 400 | `incompatible_path` | Model and endpoint path are incompatible (e.g. Claude model on `/v1/chat/completions`) |
| 400 | `invalid_metadata` | The `X-Toolken-Metadata` header contains invalid JSON |
| 401 | `missing_api_key` | The `X-Toolken-Key` header is absent |
| 401 | `invalid_api_key` | The `X-Toolken-Key` value does not match any active key |
| 402 | `budget_exceeded` | The tenant's spend budget has been reached |
| 403 | `tenant_suspended` | The tenant account has been suspended |
| 413 | `payload_too_large` | The request body exceeds the gateway payload size limit |
| 429 | `rate_limited` | The request rate limit for this tenant has been reached |
| 503 | `auth_unavailable` | The authentication backend is unavailable — the gateway fails closed |
