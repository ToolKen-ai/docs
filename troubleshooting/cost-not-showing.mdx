---
title: "Cost Not Showing in Dashboard"
description: "Steps to diagnose missing cost data in the Toolken analytics dashboard."
---

If requests are being proxied but cost is not appearing in the dashboard, check the most common causes:

- **Missing or invalid `X-Toolken-Key`** — the gateway returns `401`; requests without a valid key are not attributed to any tenant.
- **Model not in the pricing database** — cost is recorded as zero until pricing is added for that model.
- **Attribution headers missing** — spend without `X-Toolken-Feature`, `X-Toolken-Customer-Id`, or `X-Toolken-Metadata` appears under the default "unattributed" dimension.

Check the request logs in the dashboard for error codes and verify header names exactly — header names are case-insensitive but must be spelled correctly.
