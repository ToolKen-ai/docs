**Claude Code reads `ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY`, and `ANTHROPIC_CUSTOM_HEADERS` at startup -- set all three and every request is tracked in Toolken without touching your prompts or workflows.**

<Steps>

<Step title="Get your two keys">

You need two keys:

| Key | Where to get it | Looks like |
| --- | --- | --- |
| Toolken key | Dashboard, under API Keys | `tk_live_...` |
| Anthropic key | Your Anthropic account | `sk-ant-...` |

Toolken forwards your Anthropic key verbatim and never stores it.

</Step>

<Step title="Set the environment variables">

Export the three variables before launching Claude Code:

```bash
export ANTHROPIC_BASE_URL="https://gateway.toolken.ai"
export ANTHROPIC_API_KEY="sk-ant-..."
export ANTHROPIC_CUSTOM_HEADERS="X-Toolken-Key: tk_live_...
X-Toolken-Meta-Agent: claude-code"
```

<Note>`ANTHROPIC_BASE_URL` must be `https://gateway.toolken.ai` with no `/v1` at the end. Claude Code appends `/v1/messages` itself -- adding `/v1` will cause routing errors.</Note>

<Tip>`ANTHROPIC_CUSTOM_HEADERS` is newline-delimited: each `Name: Value` pair on its own line. The example above sets two headers. You can add more pairs on additional lines using the same format.</Tip>

To persist these across shell sessions, add the three `export` lines to your `~/.zshrc`, `~/.bashrc`, or equivalent profile file.

</Step>

<Step title="Run Claude Code">

Start Claude Code as normal:

```bash
claude
```

Claude Code picks up the environment variables at launch. All LLM calls are automatically routed through the Toolken gateway with `X-Toolken-Key` and `X-Toolken-Meta-Agent` attached.

</Step>

<Step title="Confirm in your dashboard">

Within seconds your first request appears in the Toolken dashboard, grouped under the `claude-code` agent. Cost, token usage, and latency are all captured automatically.

</Step>

</Steps>

## How the two keys travel

Claude Code injects your Anthropic key as `x-api-key`. Toolken reads `X-Toolken-Key` separately and forwards `x-api-key` unchanged.

| Header | Who reads it | What happens after |
| --- | --- | --- |
| `X-Toolken-Key: tk_live_...` | Toolken gateway | Stripped before forwarding |
| `x-api-key: sk-ant-...` | Anthropic | Forwarded untouched |
| `X-Toolken-Meta-Agent: ...` | Toolken gateway | Recorded as metadata key `agent`, then stripped |
