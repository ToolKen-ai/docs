---
title: "OpenAI-Compatible Clients"
description: "Use any OpenAI-compatible library or tool with Toolken by changing the base URL."
---

Because Toolken exposes a fully OpenAI-compatible `/v1/chat/completions` endpoint, any library or tool that accepts a custom `base_url` (LiteLLM, LangChain, Instructor, Marvin, Guidance, and many others) works without code changes beyond setting the gateway URL and adding the `X-Toolken-Key` header. Provider-specific endpoints like Anthropic's `/v1/messages` are also supported.
