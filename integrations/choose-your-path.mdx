---
title: "Choose Your Path"
description: "Agentic framework plugin or direct API integration — pick the right entry point."
---

There are two ways to integrate Toolken: the **Agentic** path (a native plugin or callback for your agent framework — OpenClaw, Hermes, CrewAI, LangGraph) where the framework handles header injection automatically, and the **API / Direct** path (a base-URL swap in your OpenAI-compatible SDK or a plain HTTP client) where you add attribution headers yourself. If you are building with an agent framework, start with the Agentic section; if you are calling LLM APIs directly, start with the API Quickstart.
