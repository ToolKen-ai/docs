---
title: "Headers Reference"
description: "Complete reference for all Toolken attribution headers and their reserved keys."
---

Toolken supports four attribution headers. `X-Toolken-Key` is the gateway auth token (required on every request). `X-Toolken-Feature` tags the product feature responsible for the call. `X-Toolken-Customer-Id` identifies the end-customer. `X-Toolken-Metadata` accepts a JSON object for arbitrary key-value dimensions, and `X-Toolken-Meta-*` provides a flat-header shorthand (e.g. `X-Toolken-Meta-Customer-Id`). The reserved promoted keys recognized by the dashboard are: `customer_id`, `feature`, `environment`, and `session_id`.
